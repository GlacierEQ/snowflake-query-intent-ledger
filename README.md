# Query Intent Ledger

**Problem space:** governed data reuse (Snowflake-class public design lens)  
**Innovation:** Query IDs are one-shot identities bound to purpose, columns, and SQL digest; downstream reuse must stay within the registered column boundary and an explicit purpose→use policy, with chained decision receipts.

Pairs conceptually with `snowflake-cortex-claim-bound`, but no exercised integration is claimed yet. The claim fence governs whether a natural-language claim cites registered query identities; this ledger governs declared downstream use of the query identity itself.
